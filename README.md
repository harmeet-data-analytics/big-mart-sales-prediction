# Big Mart Sales Prediction

## Project Overview
This project focuses on predicting product sales for Big Mart using Python and machine learning. The model uses historical sales data and product-related features to estimate sales.

## Project Objectives
- Analyze the provided training and testing datasets.
- Understand the factors that influence product sales.
- Build a machine learning model to predict sales.
- Generate sales predictions for the test dataset.

## Dataset
The project includes:
- **Train.csv** – Dataset used to train the machine learning model.
- **Test.csv** – Dataset used to generate predictions.
- **bigmart_submission.csv** – File containing the prediction results.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

## Project Workflow
1. Load and explore the datasets.
2. Clean and preprocess the data.
3. Prepare the features for model training.
4. Train a machine learning model.
5. Generate predictions for the test dataset.
6. Save the predicted sales results.

## Application
The project includes a Python application (`bigmart_sales_app.py`) for working with the sales prediction model.

## Project Files
- `bigmart_sales_app.py` – Python application.
- `Train.csv` – Training dataset.
- `Test.csv` – Testing dataset.
- `bigmart_submission.csv` – Prediction output.
- `requirements.txt` – Required Python libraries.

## Project Goal
To apply Python and machine learning techniques to sales prediction and develop practical data analytics skills.
